# ASICC 14차 — 메인 배너 문구·색상 강조 및 중학교 모집 예정 안내

## 적용 기준과 파일 범위

**13차 메인 배너 기능을 포함한 누적 수정 ZIP입니다.** 13차를 아직 적용하지 않았다면 이 14차 ZIP만 적용하세요. 13차가 이미 적용되어 있어도 같은 경로에 덮어쓰면 됩니다.

13차 대비 실제로 수정한 소스는 아래 **2개 파일만**입니다.

- `src/data/cms/home-campaigns.json`: 한국어·프랑스어 배너 문구, 중학교 모집 예정 문구, 후원 배너 소개 문구
- `src/components/HomeCampaigns.astro`: 배너 색상과 버튼 대비, 두 HelloAsso 버튼 문구

ZIP에 포함된 나머지 7개 소스 파일은 **13차와 바이트 단위로 동일**하며, 13차 관리자 배너 편집·CMS·모집/바자회 공지·Firebase 규칙 기능을 함께 설치하기 위해 포함했습니다.

프랑스어 문구도 같은 내용으로 함께 반영했습니다.

## 관리자 화면과 Pages CMS

13차에 포함된 **관리자 → 메인 배너 관리**와 **Pages CMS → 첫 화면 배너** 기능은 유지됩니다. 바자회·신규 모집 배너의 제목·설명·상태 문구·버튼·링크·노출 여부를 두 화면에서 수정할 수 있습니다.

**주의: 기존 관리자 편집값이 있는 경우 CMS 기본 문구 변경보다 관리자 편집값이 우선합니다.** 이때 새 문구를 보고 싶으면 관리자의 각 배너에서 `CMS 기본값 복원`을 선택하거나, 새 문구를 직접 편집해 저장하세요. 기존에 따로 편집한 문구가 있다면 복원 전에 복사해 두세요.

## 적용 순서

1. 프로젝트를 백업한 뒤, GitHub Desktop에서 `test-cms-fr` 브랜치를 선택합니다.
2. ZIP을 압축 해제해 해당 경로의 파일만 프로젝트에 덮어씁니다. **전체 폴더를 교체하지 마세요.**
3. Commit → Push origin 한 뒤 GitHub Actions의 빌드/보안 검사 결과를 확인합니다.
4. 테스트 홈페이지에서 한국어/프랑스어, PC/모바일 배너 3개, 모집/바자회 공지 연결 및 HelloAsso 두 버튼을 확인합니다.
5. 필요하면 관리자 → 메인 배너 관리에서 CMS 기본값을 복원해 새 문구를 확인합니다.
6. 정상이면 Pull Request로 `test-cms-fr` → `main` 병합하고 공식 홈페이지 배포를 확인합니다.

### Firebase 적용 조건

- **이미 13차 Firebase 규칙이 적용된 경우:** 이번 14차에서는 **Firebase, Cloudflare Worker, B2 변경이 필요 없습니다.**
- **13차를 아직 적용하지 않은 경우:** 14차 ZIP에 13차의 `firestore.rules.PROPOSED_ONLY`가 동일하게 포함되어 있습니다. GitHub 검사를 통과한 뒤 Firebase 규칙을 백업하고 해당 제안 규칙을 별도로 적용해야 관리자 배너 실시간 저장이 동작합니다. `firestore.rules`를 무심코 덮어쓰지 마세요.

## 확인한 검사

- 13차와 비교해 **배너 데이터·화면 코드 2개만 변경**, 나머지 7개 파일 동일
- JSON/YAML 구조 및 CMS 필드 확인
- 한/불 배너 문구 길이와 내부 공지 링크·기존 HelloAsso URL 검사
- 후원/바자회/모집 버튼의 흰 글자 대비 비율 확인 (WCAG AA 일반 글자 최소 4.5:1 충족)
- Astro 앞/뒤 TypeScript 스크립트 구문 및 CSS 파싱 검사

**이 환경에서 실제 Astro 전체 빌드와 Firebase 에뮬레이터, 배포된 사이트의 화면 검사는 완료하지 못했습니다.** GitHub Actions 통과 및 테스트 홈페이지 확인 후 `main`에 반영하세요.
